# Amazon Clone

A **responsive Amazon clone** built with **HTML and CSS**. This project replicates the basic layout and styling of Amazon’s homepage, including navigation, product listings, and footer.  

🌐 **Live Demo:** [https://amazon-clone-pearl-xi.vercel.app/]

---

## Features

- Fully responsive design (desktop and mobile friendly)  
- Navigation bar with search bar and user options  
- Product listing sections with cards  
- Footer with multiple links and sections  
- Styled using only HTML and CSS
